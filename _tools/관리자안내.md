# 관리자 화면

주소는 홈페이지 뒤에 `/admin.html` 을 붙이면 됩니다.

    https://testimony-nextpage.com/admin.html

검색에는 안 잡히게 해 두었습니다. 들어가려면 **관리자 코드**가 필요하고,
코드는 QR 미션 관리자 화면에서 쓰시는 것과 같습니다
(서버의 `ADMIN_KEY` 또는 `ADMIN_CODE`).

코드는 그 탭에만 잠깐 남고, 주소창에는 절대 들어가지 않습니다.
탭을 닫거나 「나가기」를 누르면 지워집니다.

## 1. 다녀간 수

| 칸 | 무엇을 센 것인가 |
|---|---|
| 홈페이지 전체 | 홈페이지를 연 횟수 |
| 온라인 전시관 | 「온라인 전시관 3D」 칸을 연 횟수 |
| 둘러보기 시작 | 실제로 360 둘러보기에 들어간 횟수 |
| 전시실별 | 둘러보기 안에서 어느 전시실까지 갔는지 |

「열어 본 수」는 횟수, 「다녀간 사람」은 **그날 처음 들어온 브라우저 수**입니다.
한 사람이 하루에 여러 번 들어오면 횟수만 올라갑니다.

날짜별 막대에 손을 올리면 그날 숫자가 나오고, CSV 로 내려받을 수 있습니다.

### 개인정보

**누가 왔는지는 남기지 않습니다.** 서버로 가는 것은 세 가지뿐입니다.

- 날짜 (한국 시간)
- 어느 화면인지 (`home` / `hall` / `tour` / `room:02` …)
- 그 브라우저가 그날 처음인지 예·아니오

IP 주소, 쿠키, 기기 정보는 쓰지 않습니다. '오늘 처음인지'를 판단하는
날짜는 보는 사람 기기 안에만 남고 서버로 오지 않습니다.
그래서 개인정보처리방침에 따로 적을 항목이 생기지 않습니다.

## 2. 문구 고치기

홈페이지에서 `data-cms="이름"` 이 붙은 자리는 관리자 화면에서 고칠 수 있습니다.
저장하면 홈페이지를 새로 고치는 즉시 바뀝니다. GitHub 에 올릴 필요가 없습니다.

- 칸을 **비우고 저장하면** 홈페이지에 원래 적힌 문구로 돌아갑니다
- 회색 글씨(힌트)로 보이는 것이 원래 문구입니다
- 전시실 이름을 고치면 둘러보기 화면 위쪽 이름과 목록도 같이 바뀝니다

### 고칠 수 있는 자리를 늘리려면

`index.html` 에서 그 자리에 `data-cms="이름"` 을 붙이면 끝입니다.
관리자 화면이 알아서 칸을 하나 더 만들어 보여 줍니다.

```html
<p class="lead" data-cms="guide.lead">건네받은 말들을 …</p>
```

이름은 영문·숫자·`. _ : -` 만 쓰고 40자 안쪽으로. 보기 좋은 이름을
붙이려면 `assets/admin.js` 위쪽 `NAMES` 에 한 줄 더하면 됩니다.

**글자만 바뀝니다.** 안에 `<br>` 이나 다른 태그가 든 자리는 붙이지 마세요
(태그가 지워집니다). 줄을 나눠야 하면 자리를 둘로 나누세요.

## 3. 서버 쪽

서버는 QR 미션과 같은 것을 씁니다 (`qr-mission-api`, Cloudflare Workers + D1).

- `POST /api/hit` — 다녀감 세기 (아무나 부를 수 있음, 개인정보 안 받음)
- `GET  /api/content` — 문구 불러오기 (아무나)
- `GET  /api/admin/visits` — 다녀간 수 (관리자 코드 필요)
- `POST /api/admin/content` — 문구 저장 (관리자 코드 필요)

표 두 개가 늘었습니다: `visits`, `content`.

### 처음 한 번만 할 일

```bash
cd ../qr-mission/server
npx wrangler d1 execute qr-mission --remote --file=./schema.sql
npx wrangler deploy
```

`schema.sql` 은 `CREATE TABLE IF NOT EXISTS` 라 여러 번 돌려도 안전합니다.

### 내 컴퓨터에서 확인할 때

```bash
cd ../qr-mission/server
npx wrangler dev --local --port 8787 --var ADMIN_KEY:test-admin-key
```

`localhost` 에서 열면 홈페이지와 관리자 화면이 알아서 이 서버를 봅니다.
처음에는 표를 만들어야 합니다.

```bash
npx wrangler d1 execute qr-mission --local --file=./schema.sql
```
