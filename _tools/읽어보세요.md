# .insp 를 360 사진으로 펴기

인스타360 카메라가 찍은 `.insp` 는 렌즈 두 개가 찍은 동그란 사진 두 장이
나란히 붙어 있는 상태라, 그대로는 360 보기에 쓸 수 없습니다.
아래 두 단계로 폅니다. 인스타360 프로그램이 없어도 됩니다.

## 1. 날것 그림 뽑기 (PowerShell)

```powershell
Add-Type -AssemblyName System.Drawing
$src = "사진.insp"          # 확장자는 그대로 둬도 됩니다 (속은 JPEG)
$bmp = New-Object System.Drawing.Bitmap $src
"$($bmp.Width) x $($bmp.Height)  stride $($bmp.Width*3)"
$rect = New-Object System.Drawing.Rectangle 0,0,$bmp.Width,$bmp.Height
$d = $bmp.LockBits($rect,[System.Drawing.Imaging.ImageLockMode]::ReadOnly,[System.Drawing.Imaging.PixelFormat]::Format24bppRgb)
$fs = [System.IO.File]::Create("full.raw")
$buf = New-Object byte[] ($d.Stride*128)
for ($y=0; $y -lt $bmp.Height; $y+=128) {
  $rows=[Math]::Min(128,$bmp.Height-$y); $n=$d.Stride*$rows
  [System.Runtime.InteropServices.Marshal]::Copy([System.IntPtr]::Add($d.Scan0,$d.Stride*$y),$buf,0,$n)
  $fs.Write($buf,0,$n)
}
$fs.Close(); $bmp.UnlockBits($d); $bmp.Dispose()
```

`Bitmap` 에 `Graphics.DrawImage` 로 그리면 이 크기(1억 2천만 칸)에서는
빈 그림이 나옵니다. 반드시 위처럼 `LockBits` 로 바로 떠내야 합니다.

## 2. 펴기

```
node insp-to-pano.js full.raw flat.bmp 8192 196 0 <가로> <세로> <stride>
```

- `8192` — 나올 가로 (세로는 절반). 휴대폰에서 열리는 한계가 8192 입니다.
- `196` — 렌즈가 보는 각도. 인스타360 X 계열은 193~200 사이입니다.
  이음매가 어긋나 보이면 이 값을 1씩 올리고 내려 보세요.
- `0` — 좌우 돌림(도). 정면을 바꾸고 싶을 때만 씁니다.

## 3. JPEG 로 바꾸기

```powershell
Add-Type -AssemblyName System.Drawing
$b = New-Object System.Drawing.Bitmap "flat.bmp"
$enc = [System.Drawing.Imaging.ImageCodecInfo]::GetImageEncoders() | ? { $_.MimeType -eq 'image/jpeg' }
$p = New-Object System.Drawing.Imaging.EncoderParameters 1
$p.Param[0] = New-Object System.Drawing.Imaging.EncoderParameter -ArgumentList ([System.Drawing.Imaging.Encoder]::Quality),([long]85)
$b.Save("pano.jpg",$enc,$p); $b.Dispose()
```

`EncoderParameter` 의 값은 반드시 `[long]` 으로 넣어야 화질이 먹습니다.
그냥 숫자로 넣으면 다른 생성자가 잡혀 무시됩니다.

## 여러 장을 한 번에 (2026-10-29 추가)

```powershell
# 폴더 통째로 — .insp 전부를 펴서 jpg 로 저장
.\_tools\pano.ps1 -In "<insp 폴더>" -Out "<나올 폴더>" -Width 4096 -Quality 82

# 어떤 사진인지 한눈에 보는 대지(contact sheet)
.\_tools\sheet.ps1 -In "<jpg 폴더>" -Out "sheet.jpg" -Cols 5 -Cell 380
```

174장을 1024 폭으로 펴는 데 85초, 4096 폭이면 5분 안팎입니다.
이미 만들어 둔 파일은 건너뛰므로 중간에 끊겨도 다시 돌리면 됩니다.

## 온라인 전시관에 넣기

1. `.insp` 를 전시실별 폴더에 나눠 담고, 파일 이름을 찍은 순서(`001.insp` …)로 바꿉니다.
   인스타360 파일 이름 끝의 `_00_045` 가 찍은 순서입니다. **이 번호로 정렬해야 합니다.**
   파일 이름 전체로 정렬하면 앞쪽 시각(`182755`)이 달라져 순서가 뒤섞입니다.
2. `pano.ps1` 로 `tour/<전시실 폴더>/` 에 jpg 를 만듭니다.
3. `node _tools/make-tour.js` — `tour/tour.json` 을 다시 만듭니다.
4. 끝. 화면 쪽은 `assets/pano.js` 가 알아서 읽습니다.

전시실 폴더 이름과 한글 이름은 `_tools/make-tour.js` 위쪽 `NAMES` 에 있습니다.

## 찍는 사람이 사진에 나오는 문제

손에 들고 찍으면 찍는 사람이 사진 한가운데를 가립니다.
사진에서 지워 메울 방법은 없어서 **모자이크로 덮었습니다.**
그 방향으로 돌아보는 것은 되고, 사람만 뭉개집니다.

값은 `_tools/make-tour.js` 아래쪽 `const out = ...` 에 있습니다.

- `yaw: 180` — 지점에 들어갔을 때 처음 보는 방향(사람 반대쪽)
- `mask` — 덮는 자리 두 덩이 `[머리, 몸]`.
  한 덩이는 `[가운데 u, 가운데 v, 반지름 u, 반지름 v]`,
  `u` 는 좌우(0~1 이 360도), `v` 는 위아래(0 이 천장, 1 이 바닥)
- `grid: 130` — 모자이크 칸 수(360도 기준). 작을수록 굵게
- `down: 34` — 아래로 볼 수 있는 한계(도). 더 열면 팔·손이 보입니다
- `nadir: [0.82, 0.93]` — 바닥 쪽을 어둡게 덮는 구간

모자이크는 `assets/pano.js` 의 `FRAG` 안에서 그립니다. 사진 파일 자체는
건드리지 않으므로, 삼각대로 다시 찍으면 **`mask` 한 줄만 지우면** 끝납니다.

- 삼각대·셀카봉에 올리고 **타이머(3초·10초)** 로 찍은 뒤 사람은 벽 뒤로 비킵니다.
- 눈높이 **150~160cm**, 기울지 않게.
- 막대기는 카메라가 알아서 지웁니다.

## 걷기 조작

- **W** 앞으로 한 지점 · **S** 뒤로 · **A** **D** 좌우로 돌아보기
- 누르고 있으면 계속 걸어갑니다. **Shift** 를 같이 누르면 빨리 걷습니다
- 끌어서 둘러보기, 휠·두 손가락으로 당겨 보기
- 한글 자판(ㅈㄴㅁㅇ)으로도 됩니다

사진은 찍은 자리에서만 볼 수 있으므로, W 는 실제로 '다음 지점'으로
옮겨 가는 것입니다. 지점을 촘촘히 찍을수록 걷는 느낌이 부드러워집니다.

## 흐릿한 사진 걸러내기

```powershell
.\_tools\blur.ps1 -Tour .\tour -Out sharp.csv
```

전시장 사진은 흰 벽이 많아서, 평균 선명도로 재면 '아무것도 없는 흰 벽'이
'흔들린 사진'과 똑같이 낮게 나옵니다. 그래서 사진을 64칸씩 잘라
**그중 가장 또렷한 쪽(p99)** 을 봅니다. 제대로 찍혔으면 글자나 액자
모서리처럼 또렷한 데가 반드시 한 군데는 있습니다.

- `p99` 500 아래 — 글자가 뭉개져 읽히지 않습니다. 빼는 게 낫습니다
- `p99` 600 위 — 벽 글자가 읽힙니다
